# 📦 Carpeta de Entregables

Esta carpeta contiene los documentos principales del proyecto listos para entregar.

## 📄 Contenido

### 1. Business_context_iris.md
Contexto de negocio del proyecto, alcance y objetivos principales según la metodología IRIS.

### 2. Hallazgos As-Is.pdf
Documento con los hallazgos del análisis del estado actual del sistema (As-Is), incluyendo problemas identificados y oportunidades de mejora.

### 3. REFINED_BACKLOG.md
Backlog refinado del proyecto con historias de usuario priorizadas y estimadas.

### 4. TEST_PLAN.md
Plan de pruebas del proyecto que incluye estrategia, alcance, recursos y cronograma de testing.

### 5. TEST_CASES.md
Casos de prueba detallados con pasos, datos de prueba y resultados esperados.

### 6. Construccion_HU_Atlas.md
Documento de construcción de Historias de Usuario siguiendo el framework Atlas.

### 7. MEJORAS.md
Resumen completo de todas las mejoras aplicadas al proyecto siguiendo buenas prácticas de desarrollo de software. Incluye:
- Reorganización de documentación (32 archivos)
- Reorganización de scripts y limpieza (5 archivos movidos, 3+ eliminados)
- Mejoras en .gitignore (15 nuevas reglas)
- Estadísticas y validaciones de funcionalidad

---

**Nota:** Estos archivos son copias de los documentos originales ubicados en:
- `docs/architecture/` - Documentación de arquitectura y negocio
- `docs/testing/` - Documentación de pruebas

Para la versión más actualizada, consulta las carpetas originales.
